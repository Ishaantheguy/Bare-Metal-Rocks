# Bare Metal Microcontroller Programming

A collection of bare-metal experiments, projects, and notes while exploring different microcontrollers.

This repository is my journey into understanding embedded systems closer to the hardware — writing code using datasheets, working with registers, and figuring out how things work underneath the abstractions provided by frameworks.

Starting with the **ATmega328P**, this repo will slowly expand to include different microcontrollers and architectures as I explore them.

The idea is simple: learn the hardware, write some low-level code, break things, debug them, and understand what is actually happening inside these tiny computers.
